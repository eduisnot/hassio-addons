# Home Assistant Add-on: Karakeep

An elegant, smart, self-hosted bookmark manager (formerly known as Hoarder) compiled directly for Home Assistant OS.

## Features

- **Save Everything:** Link bookmarks, notes, images, and text snippets.
- **AI Integration ready:** Built-in capabilities for automatic tagging (requires external configuration).
- **Auto-generated Secrets:** No manual configuration or hardcoded secrets required. Fully secure by default.
- **Persistent Storage:** All your data is safely kept inside your Home Assistant `/share` directory.

## Installation

1. Go to your Home Assistant instance.
2. Navigate to **Settings** > **Add-ons** > **Add-on Store**.
3. Click the three dots in the top right corner and select **Repositories**.
4. Paste the URL of this GitHub repository and click **Add**.
5. Find **Karakeep** in the list, click it, and hit **Install**.
6. Turn on **Show in sidebar** if you want easy access, then click **Start**.
